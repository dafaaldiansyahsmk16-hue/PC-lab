PANDUAN CEPAT

Cara menggunakan simulator

  1. Pilih Mode Panduan untuk belajar urut, atau Mode Bebas untuk mencoba sendiri.
  2. Pilih komponen pada daftar di sebelah kanan/bawah model.
  3. Tekan Pasang komponen. Pada mode panduan, pasang sesuai urutan.
  4. Geser model 3D untuk memutar. Gunakan tombol + dan − untuk zoom.

Ini prototipe edukasi: model 3D dibuat dari bentuk sederhana, bukan replika ukuran teknis komponen. Selalu ikuti instruksi guru saat praktik asli.
